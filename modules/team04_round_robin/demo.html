Round Robin CPU Scheduling

About Round Robin CPU Scheduling

Definition

Round Robin is a preemptive CPU scheduling algorithm in which each process is given a fixed amount of CPU time called a Time Quantum. Processes are executed in a circular order. When a process uses its Time Quantum, it is moved to the back of the Ready Queue if it still has remaining execution time.

How Round Robin Works

  1. Processes enter the Ready Queue according to their arrival time.
  2. The CPU selects the first process from the Ready Queue.
  3. The selected process executes for a maximum of one Time Quantum.
  4. If the process finishes before the Time Quantum expires, it leaves the Ready Queue.
  5. If the process is not finished, it is moved to the back of the Ready Queue.
  6. The CPU then selects the next process in the queue.
  7. This process continues until all processes are completed.

Important Terms

  • Time Quantum: The maximum amount of CPU time given to a process during one turn.
  • Ready Queue: The queue containing processes waiting for CPU execution.
  • Preemption: The running process can be interrupted when its Time Quantum expires.
  • Context Switching: The CPU switches from one process to another process.
  • Arrival Time: The time at which a process enters the Ready Queue.
  • Burst Time: The total CPU time required by a process for execution.

Working Example

Consider four processes P1, P2, P3 and P4 with a Time Quantum of 2 units. The CPU first executes P1 for up to 2 units. If P1 is not completed, it moves to the back of the Ready Queue. The CPU then executes P2 for up to 2 units, followed by P3 and P4. The same circular process continues until all processes are completed.

Characteristics of Round Robin

  • It is a preemptive scheduling algorithm.
  • It uses a Time Quantum.
  • Processes are handled using a circular Ready Queue.
  • Each process gets an opportunity to use the CPU.
  • A process may execute multiple times before completing.
  • Context switching occurs when the CPU moves between processes.

Scheduling Performance Terms

  • Completion Time: The time at which a process finishes execution.
  • Turnaround Time: The total time from the arrival of a process until its completion.
  • Waiting Time: The total time a process spends waiting in the Ready Queue.
  • Response Time: The time from process arrival until it first gets CPU execution.

Advantages

  • Fair CPU time is given to each process.
  • Provides good response time for interactive systems.
  • Prevents starvation of processes.
  • Simple and easy to implement.
  • Suitable for time-sharing operating systems.

Disadvantages

  • Performance depends on the selected Time Quantum.
  • A very small Time Quantum causes more context switching.
  • A very large Time Quantum makes Round Robin behave more like FCFS.
  • Context switching creates additional overhead.
  • It may result in higher average waiting time in some cases.
