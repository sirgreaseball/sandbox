# Team 5 - Contiguous Memory / Process Allocation

This module simulates contiguous memory allocation strategies for operating systems, providing an interactive demonstration of the First Fit, Best Fit, and Worst Fit algorithms. Users can dynamically modify memory blocks and process sizes, execute different allocation strategies, and visually track how processes map onto memory blocks. The module also calculates the total internal fragmentation for blocks containing processes.

## Sample Input Data

**Memory blocks:**
- Block 1 = 100 KB
- Block 2 = 500 KB
- Block 3 = 200 KB
- Block 4 = 300 KB
- Block 5 = 600 KB

**Processes:**
- P1 = 212 KB
- P2 = 417 KB
- P3 = 112 KB
## Features

- First Fit
- Best Fit
- Worst Fit
- Memory visualization
- Internal fragmentation
- External fragmentation
- Dynamic blocks/processes
- Reset
- Terminology reference
- Manual solving guide

## Terminology

This module contains simple, student-friendly definitions of important concepts related to memory allocation, such as Internal Fragmentation, External Fragmentation, Hole, and Contiguous Memory Allocation.

## Manual Solving

The module includes an educational section explaining how to manually solve First Fit, Best Fit and Worst Fit problems and calculate internal and external fragmentation step-by-step.
